# Urban Rural Learning Foundation

## About the Project

The **Urban Rural Learning Foundation** website is designed to promote experiential learning for students by connecting classroom education with real-world experiences. The website introduces educational programs focused on rural exposure, agriculture, rural livelihoods, sustainability, and skill development.

Our mission is to help students **Explore, Experience, and Grow** through meaningful learning opportunities beyond textbooks.

## Features

- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Home Section:** Introduces the organization and its educational approach.
- **About Us:** Explains the importance of practical and experiential learning.
- **Educational Programs:** Showcases five learning experiences:
  1. Rural Discovery Day
  2. Agriculture & Farming Experience
  3. Rural Livelihood Experience
  4. Water & Sustainability Experience
  5. Rural Problem-Solving Challenge
- **Why Choose Us:** Highlights curiosity, empathy, problem-solving, and sustainability.
- **Program Booking Form:** Allows schools to submit their details and preferred program date.
- **Interactive Navigation:** Includes a mobile-friendly menu and smooth scrolling.
- **Scroll Animations:** Adds visual effects to program and information cards.
- **Dynamic Copyright Year:** Automatically displays the current year.

## Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, layouts, animations, and responsive design
- JavaScript — Interactive navigation, form handling, and scroll animations
- Google Fonts — DM Sans and Playfair Display

## Installation and Setup

1. Download or clone the project repository.
2. Ensure all HTML, CSS, JavaScript, and image files are in the correct folders.
3. Open `index.html` in your web browser to view the website.

For a better development experience, open the project in Visual Studio Code and use the Live Server extension.
